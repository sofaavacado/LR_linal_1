# 3D Moebius Strip Rendering

## Обзор

Этот проект представляет собой реализацию движка для построения и визуализации **ленты Мёбиуса** с использованием **C++**, **OpenGL** и **GLFW**.

В работе реализованы:
- математические структуры для работы с 3D-геометрией,
- параметрическое задание поверхности,
- генерация сетки поверхности,
- вычисление нормалей,
- анимация параметров поверхности,
- ручная настройка преобразований и освещения,
- отрисовка треугольной сетки в 3D-пространстве.

Цель проекта — продемонстрировать понимание компьютерной графики, геометрического моделирования и работы с параметрическими поверхностями.

---

## Ключевые возможности

- Построение **ленты Мёбиуса** как параметрической поверхности
- Генерация 3D-сетки по параметрам `u` и `v`
- Разбиение поверхности на треугольники
- Вычисление нормалей для освещения
- Применение матриц:
  - вращения

  - фонового освещения
  - зависимости цвета от глубины
- Отрисовка поверхности средствами OpenGL

### Основные компоненты

- **Vec3** — структура для работы с 3D-векторами и точками  
- **Matrix4** — матрица 4×4 для пространственных преобразований

- **MoebiusStrip** — реализация параметрической поверхности ленты Мёбиуса  
- **SurfaceEngine** — движок генерации, анимации и отрисовки поверхности

## Основная логика работы

### 1. Параметризация поверхности

Лента Мёбиуса задаётся параметрически через две переменные:
- `u` — отвечает за обход вдоль поверхности
- `v` — отвечает за поперечную координату ленты

На основе этих параметров вычисляются координаты каждой точки поверхности в 3D-пространстве.

### 2. Построение сетки

Поверхность дискретизируется по параметрам `u` и `v`, после чего:
- генерируются вершины,
- создаётся треугольная сетка,
- рассчитываются нормали для освещения.

### 3. Анимация

Во времени изменяются параметры поверхности, что позволяет наблюдать динамическое изменение формы ленты.  
Дополнительно применяется плавное вращение вокруг осей X и Y.

### 4. Отрисовка

Для каждой грани:
- применяются матричные преобразования,
- рассчитывается освещённость,
- задаётся цвет,
- выполняется отрисовка треугольников.

## Как запустить

### Требования

- компилятор C++
- установленный OpenGL
- библиотека GLFW

### Сборка и запуск

Пример для среды, где настроены зависимости OpenGL и GLFW:

```bash
g++ main.cpp -o moebius -lglfw -lopengl32 -lgdi32
./moebius
````

Для Visual Studio необходимо:

* подключить GLFW,
* добавить зависимости OpenGL (`opengl32.lib`),
* собрать проект как desktop application.
